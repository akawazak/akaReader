# Glossary
- **Suwayomi** — Java manga server running extensions. [[Suwayomi]]
- **Extension / Source** — Suwayomi plugin (one extension can expose many language sources).
- **Extension store** — index URL listing installable extensions; default Keiyoushi. [[Extension Stores]]
- **Keiyoushi** — maintained community extension index.
- **FlareSolverr** — headless-browser helper Suwayomi uses for Cloudflare. [[FlareSolverr Helper]]
- **`cf_clearance`** — Cloudflare cookie signalling a passed challenge. [[Source Verification Flow]]
- **`source-verification-required`** — backend error code. [[Source Errors]]
- **Managed services** — backend + Suwayomi (+ helper) supervised by Electron. [[Startup Flow]]
- **TDZ crash** — `Cannot access 'x' before initialization` from hook deps referencing later-declared callbacks. [[Agent Rules]]
- **CBZ** — zipped image chapter archive. [[CBZ Export]]
- **Baseline scan** — first update scan that records known chapters without flagging them new. [[Chapter Updates]]
- **manga-nexus** — historical folder name of the Electron app.
